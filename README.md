# FROSTWEAR — Fashion Landing Page

Minimal, editorial fashion website inspired by the provided reference layout (clean whitespace, floating UI chips, hero cutout, and a mini gallery carousel).

## Run locally

- Open `index.html` directly in your browser, or
- Use a simple static server (recommended):

```bash
npx serve
```

## Deploy (GitHub Pages)

1. Push this repo to GitHub.
2. In GitHub: **Settings → Pages → Build and deployment**
3. Select **Deploy from a branch**
4. Choose **Branch: `main`** and **Folder: `/ (root)`**
